## 📖 About This Repository

This repository contains course materials, assignments, practical notebooks, and projects related to **Multivariate Statistical Analysis**.

The course focuses on analyzing multiple variables simultaneously to uncover hidden relationships, detect anomalies, perform statistical inference, and support data-driven decision making.

---

## 🎯 Main Topics

### Descriptive Multivariate Analysis
- Mean Vector
- Covariance Matrix
- Correlation Structure
- Principal Components

### Multivariate Outlier Detection
- Mahalanobis Distance
- Squared Mahalanobis Distance (MSD)

### Multivariate Hypothesis Testing
- Hotelling's T² Tests
- One-Sample Tests
- Two-Sample Tests
- Paired Comparisons

### Confidence Regions
- Simultaneous Confidence Intervals
- Bonferroni Correction

### Business Applications
- Customer Segmentation
- Customer Behavior Analysis
- Strategic Decision Support

---

## 🧠 Why Multivariate Analysis?

<p align="center">
  <img src="https://images.unsplash.com/photo-1460925895917-afdab827c52f" width="80%">
</p>

Unlike traditional statistical methods that analyze variables separately, multivariate techniques study multiple variables together, providing deeper insights into complex datasets.

---

## 🔬 Learning Objectives

After completing this course, students should be able to:

✔ Analyze high-dimensional datasets

✔ Interpret covariance and correlation structures

✔ Detect multivariate outliers

✔ Conduct multivariate hypothesis testing

✔ Build simultaneous confidence intervals

✔ Apply statistical findings to real-world business problems
